
# 🏦 Sistema Bancário em Java

Projeto desenvolvido durante meus estudos de programação em Java, com o objetivo de praticar lógica de programação, estruturas condicionais, laços de repetição e entrada de dados.

## 📌 Funcionalidades

- Consultar saldo da conta.
- Realizar depósitos.
- Realizar transferências.
- Confirmar ou cancelar transferências.
- Validar valores informados pelo usuário.
- Verificar saldo disponível antes de transferir.
- Tratar entradas inválidas.

## 🛠️ Tecnologias utilizadas

- Java 17
- Scanner
- Estruturas condicionais (if/else)
- Laços de repetição (while)
- Variáveis e operações matemáticas

## ▶️ Como executar

1. Tenha o Java 17 instalado.
2. Clone este repositório:

```bash
git clone https://github.com/brunasalmeida-dev/sistema-bancario-java.git
```

3. Entre na pasta do projeto.
4. Compile o arquivo:

```bash
javac Main.java
```

5. Execute:

```bash
java Main
```
